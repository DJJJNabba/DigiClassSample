Generate Learning Content

Use AI to create practice quizzes or flashcard sets on any topic. Generated content is saved as pending until a teacher approves it.

How it works

  1. 1 Choose a subject and enter a topic
  2. 2 AI generates structured learning content via OpenRouter API
  3. 3 Content is saved to SQLite database as pending
  4. 4 A teacher reviews and approves it for the shared library
  5. 5 Students can then practise with the approved content

Database Schema

subjects (
  id        INTEGER PK
  name      TEXT UNIQUE
  active    INTEGER
)

content_items (
  id           INTEGER PK
  created_by   → users.id
  subject_id   → subjects.id
  topic        TEXT
  difficulty   easy|medium|hard
  content_type quiz|flashcard
  status       pending|approved|rejected
  reviewed_by  → users.id
  created_at   TEXT
  raw_json     TEXT
)

quiz_questions (
  id             INTEGER PK
  content_id     → content_items.id
  question       TEXT
  options_json   TEXT (JSON)
  explanation    TEXT
)

user_responses (
  id              INTEGER PK
  user_id         → users.id
  question_id     → quiz_questions.id
  selected_option TEXT
  is_correct      INTEGER
  answered_at     TEXT
)
